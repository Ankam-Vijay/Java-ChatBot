what is java=Java is a high-level, object-oriented programming language developed by Sun Microsystems.
what is jvm=JVM stands for Java Virtual Machine, which executes Java bytecode on any platform.
what is jdk=JDK stands for Java Development Kit, which includes tools for developing Java applications.
what is jre=JRE stands for Java Runtime Environment, which provides libraries and JVM to run Java programs.
what is inheritance=Inheritance allows one class to acquire properties and behaviors of another class.
what is polymorphism=Polymorphism enables objects to take on many forms, allowing method overriding and overloading.
what is encapsulation=Encapsulation hides internal state and behavior, exposing only necessary parts through methods.
what is abstraction=Abstraction simplifies complex systems by exposing only essential features and hiding implementation details.
what is interface=An interface is a contract that defines method signatures without implementations.
what is abstract class=An abstract class can have both abstract and concrete methods and cannot be instantiated.
difference between interface and abstract class=Interfaces define only method signatures; abstract classes can include method bodies and fields.
what is constructor=A constructor is a special method used to initialize objects when they are created.
what is method overloading=Method overloading allows multiple methods with the same name but different parameters.
what is method overriding=Method overriding allows a subclass to provide a specific implementation of a method already defined in its superclass.
what is static keyword=The static keyword denotes that a member belongs to the class rather than instances.
what is final keyword=The final keyword prevents modification: final variables can't change, final methods can't be overridden, and final classes can't be extended.
what is exception handling=Exception handling is a mechanism to handle runtime errors using try, catch, finally, and throw.
difference between checked and unchecked exceptions=Checked exceptions are checked at compile time; unchecked exceptions occur at runtime.
what is try catch block=A try-catch block is used to handle exceptions and prevent program crashes.
what is multithreading=Multithreading allows concurrent execution of two or more threads for better performance.
what is synchronization=Synchronization ensures that only one thread accesses a resource at a time to prevent data inconsistency.
what is garbage collection=Garbage collection automatically removes unused objects to free memory.
what is package=A package is a namespace that organizes classes and interfaces.
what is import statement=The import statement allows access to classes from other packages.
what is access modifier=Access modifiers (public, private, protected, default) control visibility of classes and members.
what is this keyword=The this keyword refers to the current object instance.
what is super keyword=The super keyword refers to the parent class and is used to access its methods or constructors.
what is instanceof keyword=The instanceof keyword checks whether an object is an instance of a specific class or interface.
what is enum=An enum is a special data type that defines a set of named constants.
what is lambda expression=Lambda expressions provide a concise way to represent anonymous functions using the -> syntax.
